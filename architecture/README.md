# Architecture & Integration Decisions

This directory serves as a lightweight tracking and research ledger for experiments, architectural decisions, and integration references across the *Elite Dangerous* software fleet (`ed-schema`, `ed-transport`, `ed-telemetry`, and downstream connectors).

## Directory Structure

* `architecture/notes/`: Informal architectural notes, decision rationales, and design sketches.
* `architecture/reference/`: API specifications, contract examples, payload dumps, and external integration reference documentation.
* `architecture/research/`: Empirical protocol exploration, live endpoint test results, performance benchmarks, and rate-limiting observations.
